# 圖書館借閱

有限資源的分配規則,壓到最簡:一本書就是一冊,同一時間只能在一個人手上。
這份是詞彙表,不是規格。「做完」長什麼樣在 `docs/spec.md`,不做什麼在 `docs/non-goals.md`。

## Language

### 書與借閱

**書**:
一本實體書,同時就是唯一的一冊。沒有「一個書目底下有幾本」這件事。
_Avoid_: 館藏、副本、冊、書目

**可借 / 借出中**:
書的兩個狀態,也是僅有的兩個。可借表示現在沒有人持有它,借出中表示有。
_Avoid_: 在架上、已出借、佔用中、鎖定

**借閱紀錄**:
某位讀者在某個時刻把某本書借走這件事的憑據,連同當下算好的到期時刻。一經建立就不再改動,只會被押上歸還的結果。
_Avoid_: 借閱、借書單、訂單、loan

**未歸還 / 已歸還**:
借閱紀錄的兩個狀態。已歸還是終態 —— 一筆紀錄不會從已歸還退回未歸還,要再借同一本書是開一筆新紀錄。
_Avoid_: 進行中、開啟中、關閉、作廢

**讀者**:
借書的人。這一版不分角色,也不驗證身分。
_Avoid_: 會員、客戶、帳號、借閱人

### 時間與逾期

**借期政策**:
一本書從借出到應該還回來之間有多長。全館只有一份,而且隨時可以改 —— 改了只影響之後的借閱。
_Avoid_: 借閱規則、期限設定

**到期時刻**:
借閱紀錄上的**快照**。借出當下用當時的借期政策算好寫進紀錄,之後政策再怎麼改,這筆紀錄的到期時刻都不動。
_Avoid_: 應還日、期限、deadline

**逾期**:
不是狀態,是一筆借閱紀錄的到期時刻已經過去這件事。逾期只被記錄,不產生任何費用。
_Avoid_: 違規、欠款、罰則

**結算逾期天數**:
歸還那一刻算出來、押進借閱紀錄的數字。算完就定格,之後再看永遠是同一個值。
一筆還沒歸還的紀錄**沒有**結算逾期天數 —— 不是 0,是這個概念對它還不存在。
_Avoid_: 逾期天數(太含糊,分不出跟下面那個的差別)

**當下逾期天數**:
拿這次請求的現在時間,對著到期時刻現算出來的數字。明天再問會得到更大的值。它是投影,不是紀錄上的事實,不會被存下來。
_Avoid_: 逾期天數、即時逾期

> 這兩個詞在 API 上共用同一個欄位名 `overdue_days`,由所在的段落決定是哪一個:
> 未歸還那段是**當下逾期天數**,歷史那段是**結算逾期天數**。
> 因此「資料庫裡未歸還紀錄的該欄位是空的」與「API 在未歸還那段回一個數字」不衝突 ——
> 前者講的是儲存,後者講的是投影。

### 動作

**借出**:
把一本可借的書交給一位讀者,同時開出借閱紀錄。同一本書同時只有一個人能成功借出,其餘的人被拒絕。
_Avoid_: 預約、保留、申請

**歸還**:
讀者把自己未歸還的那筆紀錄結清。結清完那本書立刻可借,中間沒有任何過渡狀態。
_Avoid_: 還書處理、入庫、上架
