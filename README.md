# 圖書館借閱系統(library-loan-lab)

2026 iThome 鐵人賽「盡信 Claude,不如無 Code —— 心法與全端實戰」前 20 天的練習對象。

對外是圖書館借閱,對內跑的是**有限資源的分配規則**:每本書只有幾個副本、借走就少一個、
全借出時排隊預約、歸還後隊首保留 48 小時、逾時自動釋放。不收罰款(非目標 2)。

## 為什麼是這個題目

五條**能被機器裁決、而眼睛看不出來**的規則:

| # | 規則 |
|---|---|
| 1 | 同一個副本不能同時借給兩個人 |
| 2 | 保留只能給隊首,而且逾時要真的釋放 |
| 3 | 逾期天數用借閱當下的到期日快照算,不是用現在的政策算 |
| 4 | 狀態轉移只能走白名單 |
| 5 | 時間是參數,不是副作用 |

## 技術棧

Cloudflare Workers + Hono + D1 · 自製 JWT · 純 API(沒有 UI)

## 這個 repo 的用途

- `CLAUDE.md`:給 AI 的規定(不是說明書)
- `docs/spec.md`:「做完」長什麼樣
- `docs/non-goals.md`:15 條明確不做的事
- `devlog/`:AI 每次交出什麼,原文存檔不轉述
