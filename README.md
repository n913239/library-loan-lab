# 圖書館借閱系統(library-loan-lab)

2026 iThome 鐵人賽「盡信 Claude,不如無 Code —— 心法與全端實戰」前 20 天的練習對象。

對外是圖書館借閱,對內跑的是**有限資源的分配規則**,壓到最簡:一本書就是一冊,借走了別人就不能借,
還了才能借;借期 14 天,逾期只記天數,不收罰款(非目標 2)。沒有預約排隊(非目標 1)。

## 為什麼是這個題目

五條**能被機器裁決、而眼睛看不出來**的規則:

| # | 規則 |
|---|---|
| 1 | 同一本書不能同時借給兩個人 |
| 2 | 還完立刻可借,而且 `returned` 是終態 |
| 3 | 逾期天數用借閱當下的到期日快照算,不是用現在的政策算 |
| 4 | 狀態轉移只能走白名單 |
| 5 | 時間是參數,不是副作用 |

## 技術棧

Cloudflare Workers + Hono + D1 · 純 API(沒有 UI、沒有登入)
